3. ARCHITECTURAL CHANGES (CONTENT COLLECTIONS MIGRATION)
────────────────────────────────────────────────────────────────────────────────

  The legacy blog system relied on individual `.astro` files for each article. 
  This approach didn't scale and made it difficult to query, sort, and manage 
  metadata (like tags and publish dates) globally.

  The new architecture utilises Astro's Content Collections (`src/content/blog`):
    - All articles are now written in standard Markdown (`.md`).
    - Frontmatter is strictly typed and validated via Zod in `config.ts`.
    - `[slug].astro` dynamically generates the URL paths using `getStaticPaths()`.
    - This drastically cleans up the `src/pages/blog/` directory, leaving only 
      the `index.astro` and the dynamic `[slug].astro` files.
